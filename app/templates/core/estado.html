Cómo leer esto

Las dos versiones tienen que ser iguales. Si la de la base está atrasada, el despliegue subió el código pero la migración no llegó a aplicarse: la aplicación arranca igual, y falla recién cuando alguien entra a una pantalla que usa lo nuevo.

Para arreglarlo, hay que aplicar las migraciones pendientes contra la base (ver docs/despliegue.md) y volver a desplegar.
